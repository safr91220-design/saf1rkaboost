# saf1rkaboost

Игровой режим для Windows 10/11 (Python + PySide6). Освобождает ресурсы: сворачивает окна, прячет панель
задач и значки, поднимает приоритет игры, приостанавливает/закрывает только выбранные вами приложения.
**Прирост FPS не гарантируется** — проверяйте замерами.

## Запуск
1. Установите Python 3.10+ (64-бит, галочка «Add to PATH»).
2. В папке проекта:
   ```
   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python main.py
   ```
3. Сборка EXE: `build.bat` → `dist\saf1rkaboost.exe`.

## Использование
- **BOOST** — включает Gaming Mode; **Restore Desktop** — возвращает всё назад. Alt+Tab работает, Explorer не трогается.
- **Процессы** → «Обновить», отметьте приложения → «Закрыть» / «Приостановить». «Запомнить для BOOST» — эти
  приложения будут приостанавливаться при каждом включении режима. Защищены: процессы Windows, антивирусы,
  драйверы, античиты, лаунчеры, чужие аккаунты, сама игра.
- **Настройки** → автоопределение, авто-включение, ручной выбор EXE игры. После закрытия игры всё восстанавливается.
- Лог: вкладка «Лог» и файл `%APPDATA%\saf1rkaboost\saf1rkaboost.log`.

## Как проверить на реальном ПК
1. **Без игры:** BOOST → окна свернулись, панель/значки скрыты, Alt+Tab переключает окна → Restore Desktop → всё вернулось.
2. **Закрытие программы:** включите режим и закройте saf1rkaboost — рабочий стол должен восстановиться сам.
3. **Защита:** на вкладке «Процессы» убедитесь, что svchost, explorer, антивирус, драйверы серые и не выбираются.
4. **Приостановка:** откройте Блокнот/браузер → отметьте → «Приостановить» (окно зависнет) → «Возобновить все».
5. **Игра:** добавьте EXE в Настройках (или запустите игру в полноэкранном режиме) → должен прийти вопрос о включении
   режима; закройте игру → режим выключается сам.
6. **FPS (главное):** CapFrameX / PresentMon / MSI Afterburner. Одна и та же сцена 60–120 с, минимум 3 прогона
   без режима и 3 с ним. Сравнивайте средний FPS и 1% low. Разницы может не быть — это нормально.

## Ограничения
- GPU-нагрузка — только NVIDIA (`nvidia-smi`). Авто-определение — только полноэкранные окна на основном мониторе.
- Закрытый процесс восстановить нельзя; приостановка обратима.
- Окна приложений «от администратора» сворачиваются только если saf1rkaboost запущен от администратора.
- Если программа аварийно завершилась и панель осталась скрытой: `python main.py --restore` (или перезапуск Explorer).
- Не вносит правок в реестр, не отключает Defender, службы, драйверы и античит.

## Меню (по умолчанию)
Компактное окно `saf1rka_boost` с кнопкой **Performance Mode** (включить / повторное нажатие — вернуть всё обратно),
крестик закрывает программу и восстанавливает рабочий стол. Окно поверх остальных, двигается мышкой.
Полный интерфейс (процессы, настройки, лог): `python main.py --full` или ярлык на exe с параметром `--full`.
